2 · Which scene?

The number in the corner is how many spotlights a scene already has. A yellow one: spotlights saved on this computer only, not yet on Viewora.

This isn't one of your connected tours, so saving gives you a .spotlight file to add in the editor (Viewer settings → Object spotlights).

3 · Click the object

Click once on the thing you want to spotlight. A close-up opens below and the outline is traced automatically.
